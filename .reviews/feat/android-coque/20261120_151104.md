## Intention

Coque Android Hotwire Native (1.4.1) qui affiche l'app Rails ; serveur de dev joint par `adb reverse` sur
`localhost` ; path configuration embarquée et servie par Rails (`/configurations/android_v1`) ; build de l'APK en CI.

## Revue

Partie Android et CI relue par un sous-agent (bibliothèque 1.4.1 décompilée pour vérifier la correspondance des
motifs et la confiance des origines) ; partie Rails relue directement.

Points vérifiés et écartés :
- http en clair : seulement en debug et seulement vers `localhost` ; la release reste stricte (targetSdk 37) ;
- débogage de la webview et journaux : seulement en debug ; `allowBackup` désactivé ;
- aucune donnée privée versionnée (IP, e-mail, chemin, clé) ; `local.properties`, builds et keystores ignorés ;
- confiance des origines : l'origine de départ est de confiance, le bridge et le sélecteur de fichiers y ont accès ;
  l'avertissement `bridgeLoadBlockedForUntrustedOrigin` au démarrage à froid est transitoire (URL encore vide) ;
- ordre des règles : la dernière qui correspond l'emporte ; connexion et accueil en `replace_root` ;
- endpoint Rails : public, contenu fixe, présent dans l'image Docker (`config/`), non bloqué par `allow_browser`.

## Findings

### 1. Un paramètre d'URL désactivait les règles
- **Fichiers** : `config/hotwire/android_v1.json`, copie Android
- **Sévérité** : moyenne
- **Constat** : la bibliothèque compare les motifs au chemin **et** à la query string ; `/new$` ne correspond plus
  à `/plants/new?x=1`, et `/session/new?x` aurait retrouvé le gel de l'app après connexion.
- **Correction** : motifs terminés par `($|\?)` ; spec mise à jour ; vérifié sur le téléphone (modal ouverte,
  retour à l'accueil).
- **Statut** : corrigé

### 2. Documentation du serveur de dev
- **Sévérité** : moyenne (usage)
- **Constat** : `easyhome.baseUrl` vers un autre serveur en http ne peut pas marcher (http en clair limité à
  `localhost`) ; la doc disait la configuration distante « utilisée au lancement suivant », ce qui n'est pas sûr.
- **Correction** : doc et commentaire précisés.
- **Statut** : corrigé
