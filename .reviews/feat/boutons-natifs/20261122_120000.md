## Intention

PR 8 de la refonte UX (#9, #10, ADR 0014) : action principale en bouton flottant natif (« + » de la page Plantes),
actions d'une plante dans le menu ⋮ natif, pilotés par les pages via les bridge components.

## Revue

Une unité, relue par un agent : build et lint Android, Vitest, specs système, et une sonde dans Chrome avec le user
agent de l'app et un faux adaptateur natif.

Points vérifiés et écartés : pont borné et inerte, coexistence avec l'icône Réglages, clic programmatique sur un
bouton masqué (formulaire soumis avec sa confirmation, `turbo_action: replace` conservé), CSS de masquage, modals,
rotation, bas de page, dépendance (version figée, MIT, audit propre).

## Constats

1. **Bloquant — après un archivage, « Archiver » du menu ⋮ restaurait la plante** (morph : élément conservé, menu non
   renvoyé). Statut : corrigé (menu renvoyé quand ses cibles changent ; bloc d'actions dont l'id dépend de l'état,
   remplacé en entier) ; spec système dans un navigateur qui joue l'app, vérifiée en retirant le correctif.
2. **Important — fuite mémoire du registre des boutons** (`WeakHashMap` dont la valeur retient la clé). Statut :
   corrigé (`WeakReference`).
3. **Important — bouton flottant au-dessus du toast**. Statut : corrigé (toasts remontés sur les pages qui ont un
   bouton, dans l'app).
4. **Important — spec JS dépendante de l'ordre**. Statut : corrigé.
5. **Important — pas de parcours de bout en bout dans l'app**. Statut : corrigé (`spec/system/native_app_spec.rb`,
   parcours critique ajouté à `docs/tests.md`).
6. **Mineur — bouton et menu périmés après un rechargement complet**. Statut : corrigé (`onColdBootPageStarted`).
7. **Mineur — message mal formé qui ferait planter l'app**. Statut : corrigé (entrées invalides ignorées).
8. **Mineur — avertissement lint `ContentDescription`**. Statut : corrigé.
9. **Mineur — commentaires et doc sur l'ancien emplacement du +**. Statut : corrigé (ADR, revue UX, coque, tests).
10. **Mineur — clignotement possible au rechargement complet** (attribut posé après le chargement du pont). Statut :
    non corrigé, à observer sur le téléphone.

## Vérification

`CI=true bin/ci` vert (511 specs Ruby, 24 tests JavaScript, lint, audits, seeds) ; `./gradlew assembleDebug lintDebug`
vert ; sur le téléphone : bouton flottant sur Plantes seulement, menu ⋮ de la fiche, retour.
