des emojis, logo pour le web et l'app Android, couleurs de la coque (ADR 0013).

## Revue

Une unité, relue par un agent (relancée une fois après une coupure réseau).

Points vérifiés et écartés :
- toutes les classes de jetons utilisées existent dans le CSS compilé, variantes comprises ;
- contrastes WCAG AA du texte sur chaque fond (tableau dans le rapport de l'agent) ;
- icônes décoratives cachées aux lecteurs d'écran ; la cloche a un nom accessible ;

   introduisant une faute dans `HEALTH_ICONS` et dans le ternaire du journal : la spec échoue.

6. **Mineur — `icon.png` à coins transparents** (apple-touch-icon, maskable) et manifeste en rouge. Statut : corrigé
   (PNG plein bord, couleurs et nom du manifeste).
