Easy Home · maquettes v2

Refonte proposée dans docs/ux/revue-ux.md. Écrans mobiles 390 px, données fictives. Les éléments en pointillés bleus seraient natifs dans la coque Hotwire Native (case « Montrer ce qui est natif » sur chaque écran) ; tout le reste est rendu par Rails.

Écrans

Aujourd'hui Onglet d'accueil : à faire, groupé par geste, toast Annuler. Détail d'un groupe Feuille pour valider un groupe en partie ou le décaler. Maison Onglet inventaire : un domaine par ligne. Plantes Liste d'un domaine, par emplacement. Fiche d'une plante Prochaine action, état, Soins / Photos / Historique, menu ⋮. Ajout rapide Modal : photo, nom, emplacement ; le reste replié. Poubelles Autre domaine sur le même gabarit. Journal Onglet historique, tous domaines. Réglages Notifications, foyers, membres, compte. Navigation native Avant / après, onglets, path configuration, transitions. Identité et composants Palette, typographie, icônes, briques de base. Logo et icône Un toit et une coche : la maison, c'est fait.

Parcours à essayer

  1. Aujourd'hui : appuyer sur un rond « Fait », puis « Annuler » dans le toast.
  2. Aujourd'hui → « Arroser · 4 » → détail du groupe (par emplacement).
  3. Maison → Plantes → Citronnier : onglets Soins / Photos / Historique, puis menu ⋮.
  4. Maison → Poubelles : le même système pour un autre domaine.
