Navigation native

La coque Android affiche aujourd'hui « Easy Home » partout, sans onglets, avec l'en-tête web en plus. Cible : trois onglets natifs, un titre par écran, les actions dans la barre.

Avant / après, fiche d'une plante

  • Avant : barre native « Easy Home », en-tête web « Easy Home », lien « ← Mes plantes » : trois niveaux pour un titre et un retour.
  • Après : titre natif lu dans <title>, en-tête web masqué si hotwire_native_app?, actions de la plante dans la barre (bridge button et menu), onglets toujours visibles.

Chaque onglet a son propre navigateur : revenir sur Maison retrouve la fiche où l'on était. Un invité ne reçoit que l'onglet Aujourd'hui (configuration d'onglets servie par Rails, à décider).

Path configuration proposée (android_v1.json)

{
  "settings": {},
  "rules": [
    { "patterns": [".*"],
      "properties": { "context": "default", "uri": "hotwire://fragment/web", "pull_to_refresh_enabled": true } },
    { "patterns": ["/new($|\\?)", "/edit($|\\?)", "/households($|\\?)", "/today/groups/"],
      "properties": { "context": "modal", "uri": "hotwire://fragment/web", "pull_to_refresh_enabled": false } },
    { "patterns": ["^/($|\\?)", "^/maison($|\\?)", "^/journal($|\\?)"],
      "properties": { "context": "default", "uri": "hotwire://fragment/web", "presentation": "replace_root" } },
    { "patterns": ["/session/new($|\\?)", "/passwords/new($|\\?)"],
      "properties": { "context": "default", "uri": "hotwire://fragment/web", "presentation": "replace_root" } }
  ]
}

Les racines d'onglet sont en replace_root dans leur onglet ; la coque sélectionne l'onglet dont la racine correspond (logique Kotlin à écrire dans MainActivity).

Natif ou web

  • Natif : barre d'onglets, titre et sous-titre, flèche retour et geste système, croix des modals, bouton d'action (+, Ajouter), menu ⋮, plus tard boîte de confirmation native.
  • Web : tout le contenu, les formulaires, le toast, les onglets internes d'une fiche.
  • Dans le navigateur (sans coque) : une barre d'onglets web en bas et les liens retour réapparaissent ; c'est le même gabarit, rendu seulement quand hotwire_native_app? est faux.
